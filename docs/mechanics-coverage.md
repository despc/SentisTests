Список механик составлен по игре, список проверок — по коду. Чисто клиентские вещи (симметрия, планировщик
строительства, интерфейс, метки детектора руды на экране, эмоции — сервер их только пересылает другим клиентам) сюда не
входят: сервер их не видит. Проверки плагинов Sentis (`auto_rename`,
`online_reward`, `floating_lifetime`, `cleanup_exception`, `npc_build_refused`,
`landing_gear_refused`) не считаются механиками игры. Проверки запросов клиентов живут в закрытом репозитории
и здесь не описываются.

При новой проверке обновляйте строку её механики и счётчики в таблице выше.

## Что не покрыто

Всё из таблиц выше покрыто. Замечено и ещё не проверено:

- отход блока AI Defensive (точка отхода ставится, дрон не летит — README);

Контрактов сопровождения (Escort) в этой версии игры нет: типа нет в `ContractTypes_Economy.sbc`. Чисто клиентские вещи
(интерфейс, эмоции, метки детектора руды) сервер не видит.
